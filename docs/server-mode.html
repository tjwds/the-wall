Server mode — wireframes

the-wall · a pane mode for long-running dev servers · drawn at 1200×800, the app's own window size

Three Next.js dev servers and six shells is nine panes, and the auto-tiler gives all nine an equal share. The servers get a third of the wall to show output that gets glanced at rather than read, and the six shells that are actually being typed into get 18 rows each.

Server mode (⌘D) marks a pane as a server. Server panes leave the tiling grid and stack in a fixed-height dock along the bottom edge, three terminal rows tall with a status header. Everything else tiles the remaining area exactly as it does today — six panes become the 3×2 grid, at 25 rows each.

Frames 1–2 are what the app does today. Frame 3 is the proposal; 4–6 are its details; 7–8 are an alternative and an overflow case. Geometry and row/column counts on this page are computed with the app's own arithmetic — see docs/server-mode.md.
